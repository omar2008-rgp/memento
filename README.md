# متجرك الأون لاين 🛍️

متجر أون لاين متكامل وجاهز للاستخدام مباشرة. بسيط وسهل بدون تعقيدات.

## المميزات ✨

- ✅ **لوحة تحكم كاملة** لإدارة البراند والمنتجات والطلبات
- ✅ **متجر أمامي جميل** للعملاء
- ✅ **سلة المشتريات** محفوظة في المتصفح
- ✅ **إرسال الطلبات عبر واتس** مباشرة (بدون API)
- ✅ **قاعدة بيانات بسيطة** (JSON files)
- ✅ **واجهة عربية كاملة** RTL
- ✅ **متوافق مع الموبايل**

---

## التثبيت والتشغيل 🚀

### 1️⃣ تثبيت Node.js (إذا لم يكن مثبتاً)
```bash
# تحميل من: https://nodejs.org/
# اختر الإصدار LTS
```

### 2️⃣ فتح Terminal/Command Prompt في مجلد المشروع
```bash
cd estore
```

### 3️⃣ تثبيت الحزم
```bash
npm install
```

### 4️⃣ تشغيل الخادم
```bash
npm start
```

### 5️⃣ فتح في المتصفح
```
Admin:  http://localhost:3000/admin.html
Store:  http://localhost:3000/store.html
```

## كيفية الاستخدام 📖

### أولاً: إعدادات البراند (Admin)

1. اذهب إلى `http://localhost:3000/admin.html`
2. انقر على تبويب **"إعدادات البراند"**
3. ملء البيانات:
   - **اسم البراند**
   - **رقم الهاتف الرئيسي**
   - **البريد الإلكتروني**
   - **اسم الحساب المحاسبي**
   - **رابط اللوجو** (صورة)
   - **وسائل التواصل** (واتس، إنستا، تيك توك، فيسبوك)
4. اضغط **"حفظ بيانات البراند"**

### ثانياً: إضافة المنتجات (Admin)

1. انقر على تبويب **"إدارة المنتجات"**
2. اضغط **"➕ إضافة منتج جديد"**
3. ملء بيانات المنتج:
   - **اسم المنتج** (مثال: T-Shirt أحمر)
   - **السعر** (بالجنيه)
   - **الكمية المتاحة**
   - **الوصف** (اختياري)
   - **رابط الصورة** (URL مباشر)
4. اضغط **"✅ إضافة المنتج"**

**ملاحظات:**
- الكمية التي تدخلها آمنة (لن يراها المشتري)
- لكن لو الكمية أقل من 10 وحدات ستظهر للمشتري (⚠️ متبقي: X فقط)

### ثالثاً: المتجر (Store)

1. اذهب إلى `http://localhost:3000/store.html`
2. المشتري يشوف:
   - **اسم البراند واللوجو**
   - **جميع المنتجات**
   - **خيار البحث**
3. يضيف منتجات للسلة
4. يفتح السلة (🛒) ويملء بيانات الطلب:
   - الاسم الكامل
   - رقم الهاتف
   - العنوان
   - البريد (اختياري)
5. يضغط **"إرسال الطلب عبر واتس"**
6. ينفتح واتس تلقائياً برسالة محضرة وجاهزة!

### رابعاً: مراجعة الطلبات (Admin)

1. انقر على تبويب **"الطلبات"**
2. شوف جميع الطلبات اللي اتوصلت
3. كل طلب فيه جميع التفاصيل

## الأرقام والروابط 📱

### رابط الواتس الصيح:
```
https://wa.me/201012345678?text=رسالتك هنا
```

**ملاحظات مهمة:**
- الرقم يبدأ ب `20` (رمز مصر) + الرقم بدون الصفر
- مثال: `01012345678` يصير `201012345678`
- أي دول تانية: استخدم رمزها + الرقم بدون صفر

## الصور 🖼️

### رابط الصور يجب أن:
- يكون **مباشر** (اتنهي بـ .jpg أو .png)
- يعمل في **المتصفح**
- من موقع آمن ولا يحتاج login

### أمثلة صور مجاني:
- Unsplash: `https://unsplash.com/`
- Pexels: `https://pexels.com/`
- Pixabay: `https://pixabay.com/`

## نصائح وحيل 💡

### 1. تغيير المنفذ (Port)
لو المنفذ 3000 مستخدم، عدّل في `server.js`:
```javascript
const PORT = 3001; // أو أي رقم تاني
```

### 2. النسخ الاحتياطية
انسخ مجلد `data` على فترات لحفظ البيانات

### 3. تشغيل دائم (Production)
استخدم `pm2`:
```bash
npm install -g pm2
pm2 start server.js
pm2 startup
```

### 4. الأمان
- غيّر رقم المنفذ من الافتراضي 3000
- لا تترك البيانات الحساسة في الكود

## استكشاف المشاكل 🔧

### المشكلة: "Cannot find module 'express'"
**الحل:**
```bash
npm install
```

### المشكلة: "Port 3000 is already in use"
**الحل:** غيّر المنفذ في `server.js` أو أغلق البرنامج اللي يستخدمه

### المشكلة: الصور لا تظهر
**الحل:** تأكد أن رابط الصورة يعمل (جرّب في متصفح جديد)

### المشكلة: الواتس لا ينفتح
**الحل:** تأكد أن رقم الواتس يبدأ ب `20`
